# Електронний архів факультету — Обробка XML та XSLT-трансформація

Десктопний застосунок на **Python 3.11+** з графічним інтерфейсом на **PyQt6**, призначений для парсингу, пошуку та XSLT-трансформації XML-документів науково-методичного архіву факультету.

---

## 1. Архітектура та стек технологій

* **Мова та GUI:** Python 3.11+, PyQt6.
* **Менеджер оточення та залежностей:** `uv`.
* **XML-технології:**
  * `xml.sax` (SAX API) — потоковий подієво-орієнтований аналіз;
  * `xml.dom.minidom` (DOM API) — об'єктна модель документа у пам'яті;
  * `xml.etree.ElementTree` / `lxml` (LINQ to XML / ElementTree) — декларативні запити та деревоподібна навігація;
  * `lxml.etree.XSLT` — XSLT 1.0 трансформація XML у структурований HTML.
* **Патерн проєктування:** **Strategy Pattern** для динамічного перемикання алгоритмів аналізу XML під час виконання (`XmlSearchContext` + `XmlSearchStrategy`).
* **Локалізація:** Повна українізація всіх елементів інтерфейсу, повідомлень, діалогових вікон та тестових даних.
* **Чиста архітектура:** Суворе розділення обов'язків (Separation of Concerns). Шар користувацького інтерфейсу (`src/ui/`) не містить логіки парсингу та делегує всі запити відповідним сервісам.

## 3. Встановлення та запуск

Проєкт використовує сучасний менеджер пакетів **`uv`**.

### 1) Синхронізація залежностей
```bash
uv sync
```

### 2) Запуск програми
```bash
uv run python -m src.main
```
або за допомогою скрипта:
```bash
uv run oop-lab-2
```

### 3) Запуск автоматичних тестів
```bash
uv run python -m unittest discover tests
```

## 4. Особливості реалізації

1. **Динамічні атрибути елементів `<Material>`:**
   Вузли XML містять різну кількість атрибутів (наприклад: `year`, `language`, `access`, `supervisor`, `doi`, `edition`, `isbn`, `reviewer`, `honors` тощо). Усі стратегії зчитують їх у динамічний словник `attributes: dict[str, str]` без виникнення помилок `KeyError` або `AttributeError`.

2. **Динамічна підгрузка даних ("Підгрузка даних"):**
   При завантаженні XML-файлу сервіс автоматично сканує документ та витягує всі унікальні значення ключового атрибута `type` (вид матеріалу), оновлюючи випадаючий список (`QComboBox`) з обов'язковим першим пунктом `"Усі"`.

3. **Фільтрація та пошук:**
   Реалізовано комбінований регістронезалежний підрядковий пошук за ключовим словом по всіх дочірніх тегах і динамічних атрибутах у поєднанні з вибіркою за значенням атрибута.

4. **XSLT-трансформація:**
   Можливість збереження відформатованого HTML-звіту з фірмовими стилями, таблицею та бейджами, а також відкриття результату у браузері користувача.

5. **Підтвердження виходу:**
   Перевизначений метод `closeEvent` відображає діалог запиту українською мовою з кнопками **«Так»** та **«Ні»**.
